## Directory Purposes

**`app/`:**
- Purpose: Application source. Vite `root` is this folder.
- Contains: HTML shell + `src/` TypeScript/React
- Key files: `app/index.html`, `app/src/main.tsx`, `app/src/App.tsx`
- Subdirectories: `pages/`, `components/`, `lib/`, `styles/`

**`app/src/pages/`:**
- Purpose: One module per public route
- Key files: `Home.tsx`, `Sample.tsx`, `Start.tsx`, `NotFound.tsx`

**`app/src/components/`:**
- Purpose: Shared chrome and SAMPLE visuals
- Key files: `Layout.tsx`, `SiteHeader.tsx`, `SiteFooter.tsx`, `IntakeForm.tsx`, `ShopScreens.tsx`, `OwlMark.tsx`, `Reveal.tsx`, `SkipLink.tsx`

**`app/src/lib/`:**
- Purpose: Site constants and intake composition
- Key files: `site.ts`, `intake.ts`, `usePageMeta.ts`

**`public/`:**
- Purpose: Files served as-is (`robots.txt`, `sitemap.xml`, `favicon.svg`)
- Note: `og.png` / `apple-touch-icon.png` live at repo root after publish copy

**`scripts/`:**
- Purpose: Build helpers, not runtime
- Key files: `pages-spa.mjs`, `make-images.py`

**Repo root generated files:**
- Purpose: GitHub Pages “deploy from branch / `/`”
- Contains: `index.html`, `404.html`, `assets/`, `.nojekyll`
- Rule: generated by `pages-spa.mjs`; do not edit by hand (`README.md`)

## Key File Locations

**Entry Points:**
- `app/src/main.tsx`: browser mount
- `app/src/App.tsx`: routes
- `vite.config.ts`: dev/build

**Configuration:**
- `package.json`: scripts + dependencies
- `tsconfig.json`: `include: ["app/src"]`

**Core Logic:**

- `app/src/lib/intake.ts`: mailto composer
- `app/src/pages/Home.tsx`: public studio door
- `app/src/pages/Start.tsx`: $497 first step + intake
- `app/src/pages/Sample.tsx`: fictional Northfork packet
- `OFFER-SHEET.md`: internal offer defaults (not on the door)

**Testing:**
- None

**Documentation:**
- `README.md`: run locally, routes, brand locks
- `OFFER-SHEET.md`: fulfillment owner, price, exclusions

## Naming Conventions

**Files:**
- PascalCase `.tsx` for React components (`Home.tsx`, `IntakeForm.tsx`)
- camelCase `.ts` for helpers (`site.ts`, `usePageMeta.ts`)
- kebab-case for scripts (`pages-spa.mjs`, `make-images.py`)

**Directories:**
- Short plural/role names: `pages`, `components`, `lib`, `styles`

**Special Patterns:**
- No `index.ts` barrels — pages and components are imported by path
- Generated root `index.html` is not the source; source is `app/index.html`

## Where to Add New Code

| Change | Put it here |
|--------|-------------|
| New public route | `app/src/pages/` + a `<Route>` in `app/src/App.tsx` |
| Shared chrome | `app/src/components/` |
| Brand strings / email / canonical | `app/src/lib/site.ts` (and matching meta in `app/index.html` if needed) |
| Intake fields | `app/src/lib/intake.ts` + `IntakeForm.tsx` |
| Visual style | `app/src/styles/global.css` — **locked unless the work is explicitly visual** |
| Pages publish behavior | `scripts/pages-spa.mjs`, `vite.config.ts` |

**Do not add new code to:**
- Root `index.html` / `404.html` / `assets/` (generated)
- This repo for shopowloffers.com merch (different property)
